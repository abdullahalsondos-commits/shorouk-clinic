# سيستم عيادة الشروق 🦷☀️

سيستم إدارة لعيادة الشروق لطب وجراحة الفم والأسنان. فيه ملفات المرضى والملاحظات، والعلاجات والزيارات والمدفوعات والخصومات، وسجل لكل الزيارات، والفواتير، والحسابات (60% للعيادة و40% للدكتور) شهر بشهر.

- **الموقع:** Vercel (مجاني)
- **الداتابيز وتسجيل الدخول:** Supabase (مجاني)
- **من غير ما تدفع أي حاجة.**

---

## الخطوة 1: اعمل قاعدة البيانات على Supabase (حوالي 5 دقايق)

1. ادخل على **supabase.com** واعمل حساب (ينفع بحساب GitHub أو Google).
2. اضغط **New project**:
   - Name: `shorouk-clinic`
   - Database Password: اكتب باسورد قوي واحفظه عندك
   - Region: اختار **Frankfurt (eu-central-1)**، دي أقرب حاجة لمصر
   - اضغط **Create new project** واستنى دقيقة لحد ما يخلص.
3. من القائمة اللي على الشمال اختار **SQL Editor**، بعدين **New query**.
4. افتح ملف `supabase/schema.sql`، انسخه كله، والصقه هناك، واضغط **Run**.
   لازم يطلعلك `Success`.
5. **اقفل التسجيل العام:** ادخل **Authentication**، بعدين **Sign In / Providers** (أو Settings)، واقفل **Allow new users to sign up**. كده محدش يقدر يعمل حساب لنفسه، والأدمن بس هو اللي يضيف الدكاترة.
6. **اعمل حساب الأدمن بتاعك:** ادخل **Authentication**، بعدين **Users**، واضغط **Add user** واختار **Create new user**:
   - Email: اكتب **`admin@shorouk.clinic`** (الجزء اللي قبل @ هو اسم المستخدم، يعني هتدخل بـ `admin`)
   - Password: الباسورد بتاعك
   - علّم على **Auto Confirm User**
   - أول مستخدم بيتعمل بيبقى **المدير** أوتوماتيك ✅
   - ولو عايز اسم مستخدم تاني، اكتب مثلاً `hamada@shorouk.clinic` وادخل بـ `hamada`
7. **هات المفاتيح:** ادخل **Project Settings**، بعدين **API Keys**:
   - انسخ الـ **Publishable key** (بيبدأ بـ `sb_publishable_`)
   - انسخ الـ **Secret key** (بيبدأ بـ `sb_secret_`). ده سري جداً.
   - ولو ملقتهمش، اضغط **Create new API keys**.
   - وانسخ كمان الـ **Project URL** (من زرار **Connect** فوق، أو من **Data API**). شكله كده: `https://xxxx.supabase.co`

## الخطوة 2: حط المفاتيح في الكود

افتح `js/config.js` واملاه كده:

```js
window.CLINIC_CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY: 'sb_publishable_xxxxxxxx',
};
```

> ⚠️ الـ **Secret key** أوعى تحطه هنا خالص. مكانه Vercel بس (الخطوة 4).

## الخطوة 3: ارفع الكود على GitHub

1. اعمل حساب على **github.com**.
2. اضغط **New repository**، واكتب الاسم `shorouk-clinic`، وخليه **Private**، واضغط Create.
3. اضغط **uploading an existing file**، واسحب **كل الملفات والفولدرات** اللي جوه فولدر المشروع (`index.html` و `css` و `js` و `api` و `assets` و `supabase` و `vercel.json`)، واضغط **Commit changes**.

## الخطوة 4: انشر الموقع على Vercel

1. ادخل **vercel.com** وسجّل بحساب GitHub.
2. اضغط **Add New**، بعدين **Project**، واختار الـ repo `shorouk-clinic` واضغط **Import**.
3. Framework Preset: **Other**، وسيب باقي الإعدادات زي ما هي.
4. افتح **Environment Variables** وضيف متغيرين:

   | Name | Value |
   |---|---|
   | `SUPABASE_URL` | `https://xxxx.supabase.co` |
   | `SUPABASE_SECRET_KEY` | `sb_secret_xxxxxxxx` |

5. اضغط **Deploy**. بعد دقيقة هيديك لينك زي `shorouk-clinic.vercel.app` 🎉
6. ارجع لـ Supabase، وادخل **Authentication**، بعدين **URL Configuration**، وحط لينك Vercel في **Site URL**.

## الخطوة 5: ابدأ الشغل

1. افتح اللينك وادخل باسم المستخدم `admin` والباسورد بتاعك.
2. لو حد تاني هيستخدم السيستم (الاستقبال مثلاً): ادخل **الإعدادات**، بعدين **المستخدمين**، واضغط **إضافة مستخدم** (الاسم، واسم المستخدم بالإنجليزي، والباسورد).
3. قائمة العلاجات والأسعار جاهزة (Extraction 350، Endo Posterior 1500...)، وتقدر تعدّلها من **الإعدادات**، بعدين **العلاجات والأسعار**.

## إزاي السيستم بيشتغل

| | |
|---|---|
| **الرئيسية** | سجل بكل اللي جم وعملوا إيه: النهاردة، امبارح، الأسبوع، الشهر، أو أي فترة. تقدر تبحث، ولو دوست على أي حد يفتح ملفه. |
| **مريض جديد** | الاسم، والتليفون، والسن، وملاحظات طبية (بتظهر بالأحمر). |
| **ملاحظات** | في ملف كل مريض مكان تكتب فيه أي حاجة عايزها، ويبان مين كتبها وإمتى. |
| **علاج جديد** | تختار العلاج (Endo Posterior مثلاً)، والسعر بيتملى لوحده، وتكتب **الخصم** فيطلعلك المطلوب بعد الخصم، وتسجّل اللي اتدفع النهاردة. |
| **زيارة / دفعة** | كل مرة المريض ييجي تسجّل اتعمل إيه ودفع كام، وتقدر تضيف خصم وقتها. السيستم بيحسب **الباقي** لوحده. |
| **الفواتير** | تسجّل أي مصروف: اسمه (إيجار، خامات، معمل...)، ومبلغه، وتاريخه، وملاحظات. وكمان بيوريك الفلوس راحت فين في الشهر. |
| **الحسابات** | تختار شهر أو فترة. بيطلعلك اللي اتقبض، والفواتير، و**نصيب العيادة 60%**، و**نصيب الدكتور 40%**، والخصومات، والدخل حسب كل علاج. فيه جدول **كل الشهور**، تدوس على أي شهر يفتحهولك، والمرضى اللي عليهم فلوس، وتصدير Excel. |

**تذكرني:** لو معلّم عليها، بتفضل مسجّل دخول على الجهاز ده. ولو شلتها، بتخرج أوتوماتيك أول ما تقفل المتصفح (مناسبة لو الجهاز بيستخدمه كذا حد).

**الحساب بيتعمل إزاي؟** (اللي اتقبض فعلاً في الشهر − الفواتير)، وبعدين بيتقسم 60% للعيادة و40% للدكتور. يعني لو المريض دفع 200 النهاردة والباقي الشهر الجاي، كل دفعة بتتحسب في شهرها. ولو عايز الفواتير تتخصم من نصيب العيادة بس، غيّرها من **الإعدادات**، بعدين **نسب التقسيم**.

### الصلاحيات
- **المدير:** يقدر يعمل كل حاجة، وكمان يضيف المستخدمين ويوقفهم، ويغيّر الأسعار والنِسَب، ويمسح.
- **المستخدم العادي:** يشوف كل حاجة، ويضيف مرضى وعلاجات وزيارات وفواتير، ويعدّل اللي هو سجّله بس.
- الحماية دي متطبقة جوه الداتابيز نفسها (Row Level Security)، مش في الشكل بس.

## حاجات مهمة

- **نسخة احتياطية:** الخطة المجانية مفيهاش backup أوتوماتيك، فادخل **الإعدادات**، بعدين **نسخة احتياطية**، ونزّل نسخة Excel **كل أسبوع**.
- **Supabase بيوقف المشروع المجاني لو مفيش استخدام 7 أيام.** السيستم فيه مهمة أوتوماتيك على Vercel (`/api/keep-alive`) بتشتغل كل يوم عشان تمنع ده. ولو اتوقف لأي سبب، ادخل Supabase واضغط **Resume project** والبيانات بترجع زي ما هي.
- **المساحة:** 500 ميجا، ودي تكفي عشرات الآلاف من المرضى والزيارات.

## تعديل الشكل أو الألوان

- الألوان كلها في أول ملف `css/style.css` (`--navy`، `--sky`، `--sun`...).
- اللوجو في `js/logo.js`، وأنيميشن البداية في `js/splash.js` وفي `css/style.css`.
- أي تعديل: عدّل الملف على GitHub، وVercel بينشر التحديث لوحده في دقيقة.

```

```
